# 지각비 정산 앱 기획서

## 1. 서비스 개요

### 서비스명
가칭: Don't Be Late

### 한 줄 소개
약속에 늦는 상황을 벌칙이 아닌 유쾌한 게임처럼 풀어내고, 기다린 사람에게는 기다린 시간만큼 보상이 돌아가도록 설계한 지각비 정산 앱.

### 기획 배경
친구, 동아리, 스터디, 모임에서 지각은 자주 발생하지만 이를 매번 말로 따지거나 감정적으로 처리하기는 어렵다. 이 앱은 지각비를 사전에 합의된 규칙과 입찰 시스템으로 정하고, 실제 도착 시간과 대기 시간을 기반으로 자동 정산하여 지각 문제를 공정하고 가볍게 다루는 것을 목표로 한다.

### 핵심 가치
- 공정함: 지각비와 보상 기준을 사전에 정하고 자동 계산한다.
- 유쾌함: 룰렛, 포인트, 찬스권 등 게임 요소로 어색함을 줄인다.
- 투명함: 위치 공유와 도착 인증으로 불필요한 논쟁을 줄인다.
- 보상성: 기다린 사람도 기다린 시간에 비례해 지각비를 나눠 받는다.

## 2. 주요 사용자

### 주 사용자
- 친구 모임을 자주 가지는 대학생 및 사회초년생
- 스터디, 동아리, 프로젝트 팀 등 정기적으로 만나는 소규모 그룹
- 지각 문제를 직접 지적하기보다 재미있는 규칙으로 해결하고 싶은 사용자

### 사용자 니즈
- 약속 시간과 장소를 쉽게 등록하고 싶다.
- 지각비를 일방적으로 정하지 않고 모두가 납득할 방식으로 정하고 싶다.
- 누가 얼마나 늦었는지 자동으로 확인하고 싶다.
- 기다린 사람에게도 적절한 보상이 있었으면 좋겠다.
- 모인 포인트를 재미있게 사용할 수 있었으면 좋겠다.

### 메뉴별 역할

### 방 페이지
방은 사용자가 반복적으로 만나는 모임 단위이다. 친구 모임, 스터디, 동아리, 프로젝트 팀처럼 같은 멤버가 여러 약속을 만들 수 있는 공간으로 사용한다.

주요 기능:
- 방 만들기: 방 이름을 입력하면 방 코드가 자동 생성된다.
- 방 참여하기: 초대받은 사용자가 방 코드를 입력해 방에 들어온다.
- 방 삭제: 사용자가 선택한 방을 삭제한다. 방장 권한 또는 참여자 권한 정책은 추후 정의한다.

### 멤버 페이지
현재 방에 참여하고 있는 멤버를 확인하는 화면이다. 약속 생성, 입찰, 정산, 위치 보기의 기준이 되는 참가자 목록을 제공한다.

주요 기능:
- 멤버 목록 확인
- 프로필 사진과 이름 표시
- 멤버별 지각온도 또는 최근 참여 상태 표시 확장 가능

### 약속 페이지
방 안에서 실제 약속을 만들고 관리하는 화면이다.

주요 기능:
- 약속 만들기: 장소, 시간, 참여 가능 인원을 선택한다.
- 약속 삭제: 선택한 약속을 삭제한다.
- 약속별 상태 표시: 입찰 전, 입찰 중, 실행 대기, 실행 중, 정산 완료 등으로 구분한다.

### 입찰 페이지
약속에 참여하는 사용자들이 분당 지각비를 제출하고, 최종 지각비를 룰렛으로 결정하는 화면이다.

주요 기능:
- 지각비 입찰: 사용자에게 분당 지각비를 입력받는다.
- 지각비 룰렛: 입력받은 지각비에서 이상치를 제거한 뒤 4분위 구간 룰렛을 돌려 최종 지각비를 결정한다.

### 약속 실행 페이지
약속 당일에 사용하는 핵심 화면이다. 도착 인증, 친구 위치 확인, 도착 현황 확인, 경주마 베팅 기능이 이 페이지에 모인다.

주요 기능:
- 체크인: GPS 기준 약속 장소 50m 이내에 들어오면 활성화된다.
- 도착 정보: 모임원들의 도착 여부와 도착 시간을 확인한다.
- 멤버 위치 보기: 친구들의 실시간 위치를 지도에서 확인한다.
- 경주마: 아직 도착하지 않은 지각생들에게 포인트를 베팅하는 재미 요소를 제공한다.

### 마이페이지
개인 계정, 포인트, 지각 기록을 관리하는 화면이다.

주요 기능:
- 포인트 관리: 잔여 포인트와 사용 내역을 확인한다.
- 개인정보 관리: 이름 수정, 프로필 사진 설정을 제공한다.
- 지각온도: 사용자의 지각 성향을 시각적으로 보여준다.

### 상점 페이지
사용자가 보유 포인트로 상품을 확인하고 구매하는 화면이다.

주요 기능:
- 상품 목록 확인

## 5. 주요 기능 상세

## 5.1 약속 생성

### 입력 항목
- 약속명
- 약속 날짜 및 시간
- 약속 장소
- 참가자 초대
- 입찰 마감 시간
- 지각 인정 기준
- 위치 공유 사용 여부
- 포인트/현금 정산 방식

### 기본 규칙
- 입찰 마감은 약속 시간 2시간 전으로 설정한다.
- 약속 참가자는 마감 전까지 분당 지각비를 제출해야 한다.
- 모든 참가자가 입찰을 완료하면 지각비 결정 단계로 넘어간다.
- 입찰 마감 시점까지 미입찰자가 있으면 기본 정책에 따라 처리한다.

### 미입찰자 처리 제안
- 1안: 미입찰자는 해당 약속 참가 불가 처리
- 2안: 미입찰자는 자동 기본값으로 입찰 처리
- 3안: 방장이 입찰 마감 후 강제 제외 또는 기본값 적용 선택

초기 버전에서는 3안을 추천한다. 모임 성격에 따라 유연하게 운영할 수 있기 때문이다.

## 5.2 지각비 입찰

### 목적
지각비를 방장이나 특정 사람이 일방적으로 정하지 않고, 참가자들이 직접 적정하다고 생각하는 분당 금액을 제출하게 한다.

### 입찰 방식
- 참가자는 분당 지각비를 숫자로 입력한다.
- 예: 100원/분, 300원/분, 500원/분
- 입찰값은 모든 참가자가 제출하기 전까지 비공개로 유지한다.
- 모든 입찰이 완료되면 결과를 공개하고 계산을 진행한다.

### 이상치 제거
입찰 결과 중 지나치게 낮거나 높은 값이 전체 분위기를 해칠 수 있으므로 이상치를 제거한다.

제안 방식:
- 입찰값을 오름차순 정렬한다.
- 참가자가 5명 이상일 경우 최저값 1개와 최고값 1개를 제외한다.
- 참가자가 4명 이하일 경우 이상치 제거 없이 진행한다.
- 고도화 버전에서는 IQR 방식으로 이상치를 제거할 수 있다.

## 5.3 4분위 룰렛 기반 지각비 결정

### 목적
단순 평균보다 재미있는 게임성을 부여하면서도 입찰값의 분포를 반영한다.

### 진행 방식
1. 이상치를 제거한 입찰값을 정렬한다.
2. 값을 4개 분위 구간으로 나눈다.
3. 각 분위 구간을 룰렛 칸으로 구성한다.
4. 룰렛을 돌려 최종 분당 지각비를 결정한다.

### 분위 구간 예시
입찰값: 100, 200, 300, 400, 500, 600, 700, 800

- 1분위: 100~200원
- 2분위: 300~400원
- 3분위: 500~600원
- 4분위: 700~800원

룰렛 결과가 3분위라면 해당 구간의 대표값을 최종 지각비로 사용한다.

### 대표값 산정 제안
- 구간 평균값 사용
- 구간 중앙값 사용
- 구간 내 랜덤값 사용

초기 버전에서는 구간 평균값을 추천한다. 예측 가능성과 공정성이 높다.

## 5.4 도착 인증

### 목적
약속 장소에 실제로 도착한 시점을 기준으로 지각 여부를 판단한다.

### 인증 방식
- 사용자의 GPS 위치가 약속 장소 반경 안에 들어오면 도착 인증 가능
- 사용자가 직접 도착 인증 버튼을 누른 시각을 기록
- 위치 오차를 고려해 약속 장소 기준 반경을 설정

### 반경 기준 제안
- 기본 50m
- 장소 특성에 따라 30m~100m 조정 가능

### 예외 처리
- GPS 오류 신고
- 지하/실내 위치 오차 신고
- 방장 승인 방식의 수동 인증

## 5.5 친구 위치 보기

### 기능 설명
약속 장소에 도착한 사용자는 `친구들 위치보기` 버튼을 누를 수 있다. 버튼을 누르면 약속 참가자의 위치가 지도에 실시간으로 표시된다.

### 사용 조건
- 사용자가 약속 장소에 도착 인증을 완료해야 한다.
- 해당 약속에서 위치 공유가 활성화되어 있어야 한다.
- 참가자가 위치 공유 권한을 허용해야 한다.

### 지도 표시 정보
- 친구별 프로필 아이콘
- 현재 위치
- 약속 장소까지의 예상 거리
- 예상 도착 시간
- 마지막 위치 업데이트 시간

### 개인정보 보호 정책 제안
- 위치 공유는 해당 약속 시간 전후로만 제한한다.
- 예: 약속 1시간 전부터 약속 종료 후 30분까지
- 약속 종료 후 위치 기록은 지도에서 사라진다.
- 사용자는 언제든 위치 공유를 중단할 수 있다.
- 실시간 위치는 정산 목적보다 친구 간 확인과 재미 요소로 사용한다.

## 5.6 지각비 계산 및 분배

### 지각비 계산
지각한 사람의 지각비는 다음 공식으로 계산한다.

```text
지각비 = 지각 시간(분) x 최종 분당 지각비
```

예시:
- 최종 분당 지각비: 300원
- A의 도착 시간: 약속 시간보다 12분 늦음
- A의 지각비: 12 x 300 = 3,600원

### 기다린 사람 보상 분배
기다린 사람들은 각자 기다린 시간에 비례하여 모인 지각비를 나눠 가진다.

```text
개인 보상액 = 전체 지각비 x 개인 대기 시간 / 전체 대기 시간 합계
```

예시:
- 전체 지각비: 6,000원
- B 대기 시간: 10분
- C 대기 시간: 20분
- 전체 대기 시간: 30분
- B 보상액: 6,000 x 10 / 30 = 2,000원
- C 보상액: 6,000 x 20 / 30 = 4,000원

### 대기 시간 기준
- 약속 시간 정각 또는 본인 도착 시간 중 더 늦은 시점부터 계산한다.
- 지각자가 도착하기 전까지 기다린 시간을 대기 시간으로 본다.
- 본인도 늦게 도착한 경우, 늦기 전 시간에 대한 보상은 받을 수 없다.

### 정산 방식
초기 버전에서는 앱 내 포인트로 정산하는 방식을 추천한다.

장점:
- 실제 현금 정산보다 구현과 운영 부담이 낮다.
- 상점 기능과 자연스럽게 연결된다.
- 사용자 간 금전 갈등을 줄일 수 있다.

향후 버전에서는 간편결제 연동 또는 모임별 현금 정산 기능을 추가할 수 있다.

## 5.7 포인트 상점

### 목적
지각비와 보상을 앱 내부 경제 시스템으로 연결하여 지속적인 사용 동기를 만든다.

### 상품 카테고리
- 기프티콘
- 이모티콘
- 프로필 꾸미기 아이템
- 지각 면제 찬스권
- 지각비 할인권
- 룰렛 재도전권
- 친구 놀리기용 리액션 아이템

### 찬스권 예시
- 1회 지각 5분 면제권
- 지각비 50% 할인권
- 룰렛 한 번 다시 돌리기권
- 위치 공유 10분 숨기기권

### 찬스권 제한 정책
찬스권이 지나치게 공정성을 해치지 않도록 제한이 필요하다.

- 약속 시작 전까지만 사용 가능
- 모임장이 특정 찬스권 사용 가능 여부 설정
- 한 약속당 1개만 사용 가능
- 정산 완료 후에는 사용 불가

## 7.5 약속 실행 페이지
### 구성 요소
- 약속 장소 지도
- 체크인 버튼
- 도착 정보 목록
- 멤버 위치 보기 버튼
- 경주마 베팅 영역
- 최종 정산 상태

### 체크인
GPS 기반으로 사용자가 약속 장소 50m 이내에 진입했을 때 체크인 버튼을 활성화한다. 체크인 시각은 지각 시간과 대기 시간 계산의 기준으로 사용한다.

### 도착 정보
모임원들의 도착 여부를 목록으로 보여준다. 각 멤버별 상태는 도착, 이동 중, 위치 미공유, 지각 가능성 있음 등으로 확장할 수 있다.

### 멤버 위치 보기
사용자가 체크인을 완료하면 멤버 위치 보기 버튼을 사용할 수 있다. 버튼을 누르면 친구들의 실시간 위치가 지도에 표시된다.

### 경주마
아직 도착하지 않은 지각생들을 대상으로 누가 먼저 도착할지 포인트를 베팅하는 게임 요소이다. 베팅은 약속 실행 중에만 가능하며, 실제 정산과 구분되는 별도 재미 포인트로 운영하는 것을 추천한다.

## 10. 정책 및 예외 상황

### 위치 관련
- 위치 권한을 허용하지 않은 사용자는 실시간 위치가 표시되지 않는다.
- 위치 공유를 끈 사용자는 다른 사람의 위치 보기에도 제한을 둘 수 있다.
- GPS 오류 발생 시 수동 인증 요청 기능을 제공한다.

### 지각비 관련
- 정산 전 지각비 결과를 명확히 고지한다.
- 지각비 상한선을 설정해 과도한 금액을 방지한다.
- 미성년자 사용 가능성을 고려하여 현금성 결제는 신중히 설계한다.

### 분쟁 방지
- 도착 시간 기록 로그를 남긴다.
- 수동 수정은 방장 승인과 참가자 동의를 거치도록 한다.
- 정산 완료 후 일정 시간 내 이의 제기 기능을 둔다.

## 12. UX 톤앤매너

### 서비스 분위기
- 비난보다 장난스러운 분위기
- 벌금보다 게임 규칙에 가까운 표현
- 지각자를 공격하지 않고 모두가 웃고 넘길 수 있는 문구

### 문구 방향
- 너무 딱딱한 금융/벌칙 용어를 피한다.
- 결과는 투명하게 보여주되, 말투는 가볍게 유지한다.
- 사용자가 민망하지 않도록 완충 문구를 사용한다.

### 예시 문구
- 오늘의 시간값이 정해졌어요.
- 기다림이 포인트가 되는 중입니다.
- 조금 늦었지만, 정산은 깔끔하게 갈게요.
- 먼저 온 친구들에게 작은 보상이 도착했어요.

## 14. 리스크 및 고려사항

### 법적/정책 리스크
- 현금성 지각비가 실제 금전 거래로 이어질 경우 결제, 환불, 미성년자, 전자금융 관련 검토가 필요하다.
- 위치 정보는 민감정보에 가까우므로 명확한 동의와 제한적 사용이 필요하다.

### 서비스 리스크
- 지각비가 갈등을 키울 수 있다.
- 위치 공유가 부담스럽게 느껴질 수 있다.
- 입찰 금액이 과도하게 높아질 수 있다.

### 대응 방안
- 지각비 상한선 설정
- 위치 공유 시간 제한
- 방장 설정 기능 제공
- 포인트 중심 정산
- 이의 제기 및 수동 조정 기능 제공

## 16. 결론

Don't Be Late는 지각이라는 민감하고 반복적인 문제를 공정한 규칙, 실시간 위치 확인, 게임화된 정산, 포인트 상점으로 풀어내는 소셜 약속 관리 앱이다. 핵심은 지각자를 벌주는 것이 아니라, 약속을 기다린 사람의 시간을 인정하고 모두가 납득할 수 있는 방식으로 상황을 정리하는 데 있다.

초기 버전에서는 포인트 기반 정산, 입찰 기반 지각비 결정, 도착 인증, 기본 상점을 중심으로 MVP를 구성하고, 이후 실시간 위치 공유 고도화, 기프티콘 연동, 결제 기능, 모임별 랭킹 등을 추가하는 방향이 적합하다.
